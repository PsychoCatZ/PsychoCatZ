# Привет, я Кот 🐈‍⬛

Меня зовут Павел. Я создаю собственные программы, исследую поведение ИИ и проверяю идеи на практике. Так появилась моя лаборатория — НИИ ИИ КотоИмперии / DES (DeepS Expert System).

В разработке мне помогают ИИ-агенты. Я определяю задачи, принимаю решения по проектам и проверяю результат. Большинство инструментов начинается с конкретной потребности: собрать материалы заказа, не забыть о платеже или увидеть состояние своих серверов. Иногда вместо рабочего инструмента получается игра или цифровой зверёк.

## Несколько проектов

- [DES Studio](https://github.com/PsychoCatZ/DES-Studio-Bot-public) — Telegram-каталог, пошаговые заявки и переписка по обращению.
- [KotoLancer](https://github.com/PsychoCatZ/KotoLancer-public) — личная мастерская: карточки заказов, материалы, вопросы и договорённости.
- [ХВОСТ](https://github.com/PsychoCatZ/XBOCT-public) — дела, платежи и напоминания в Telegram, Mini App и браузере.
- [DES Control Center](https://github.com/PsychoCatZ/DES-control-center-public) — Windows-панель для наблюдения за Linux-серверами, сайтами и службами.
- [KotMail](https://github.com/PsychoCatZ/KotMail) — экспериментальный MCP-коннектор для чтения Яндекс Почты без операций изменения.
- [NeuroCritter](https://github.com/PsychoCatZ/NeuroCritter-public) — виртуальный питомец с состоянием, памятью и языковой моделью.

В публичных репозиториях есть собственные инструменты, очищенные копии рабочих проектов и демонстрационные разработки. Статус, ограничения и условия запуска описаны в README каждого проекта.
